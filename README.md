# Nivash Portfolio

A responsive, single-page developer portfolio built with semantic HTML, CSS, and lightweight JavaScript.

## Live site

[nivash-portfolio.pages.dev](https://nivash-portfolio.pages.dev)

## Preview locally

From the repository root, run:

```powershell
npx serve .
```

Then open the local URL shown in the terminal.

The site can also be deployed directly to GitHub Pages, Netlify, Vercel, or any static web host.
